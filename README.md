# ゆるかわBGMコンポーザー (Yurukawa BGM Composer)

激しいビートや過度な音圧を徹底排除し、Z世代の女の子が思わず「かわいい！」「癒やされる…」と脱力してしまう、ぽかぽか・おひるね・トイポップなBGMプロンプト設計ツールです。

---

## 概要

本ツールは、ちいかわ、すみっコぐらし、サンリオ、お昼寝カフェBGMのような「ゆるくて温かい無害な可愛さ」に特化しています。  
マシュマロのようなパステルカラーのUIで、直感的にシチュエーションや楽器、ぽよんとした効果音を選ぶだけで、Suno、Udio、Google Flow Musicなどの音楽生成AIに最適なプロンプトを自動作成します。

さらに、ブラウザの音源合成機能（Web Audio API）により、オルゴールや木琴、シャボン玉の音色がぽろぽろと鳴る「癒やしのリアルタイム試聴機能」を搭載しています。

## 主な機能と特徴

### 1. 激しさゼロ・癒やし100%のサウンド設計
- **激しい要素の完全シャットアウト**: 重いドラム、EDMドロップ、トラップビート、ディストーション、うるさいシンセ、叫び声をプロンプトおよびネガティブプロンプトで徹底的に除外します。
- **癒やしの音色**: オルゴール、トイピアノ、まろやかローズピアノ、マリンバ（木琴）、ウクレレ、ぷくぷく水滴音、チェレスタなど、耳に痛くない角の取れた音色を中心に編成します。
- **ゆるかわ効果音**: 「ぽよ〜ん」「ころん」「ぷくぷく」「にゃ〜ん」「ふわぁ〜（あくび）」「チリン」など、思わず頬が緩むアクセント音を散りばめます。

### 2. ぽろぽろ癒やしプレビュー音源（Web Audio API）
- 外部音声ファイルを一切読み込まず、ブラウザ上でリアルタイムにオルゴール、木琴、シャボン玉、ウッドブロックの音を合成・演奏します。
- テンポ（60〜105 BPMのお昼寝ペース）や調性（陽だまりメジャー7th、あまいadd9、ペンタトニックなど）に同期し、光るしずくインジケーターとともにリラックスした試聴ができます。

### 3. 曲名・テーマ入力＆「🎲 曲名ガチャ」
- 自由な曲名やコンセプト（例: 「ねこのおひるねワルツ」「もふもふマシュマロ村」など）を入力でき、プロンプト本文やAI向けタグに自然に組み込まれます。
- 「🎲 曲名ガチャ」ボタンを押すと、可愛らしい曲名候補をワンクリックでサジェスト・入力できます。

### 4. プリセット保存・自動連動
- 設定を名前付きで保存・呼び出しできます。プリセット名が空欄の場合は入力中の曲名が自動的にプリセット名として採用されます。
- JSONファイルでの書き出し/読み込み、共有URLのコピーにも完全対応しています。

### 5. マシュマロパステルUI（スマホ完全対応 & PWA）
- やわらかなミルククリーム背景に、サクラピンク、ミント、カスタードイエローのぷっくり丸いマシュマロカードデザイン。
- スマートフォン表示に完全最適化されており、「ホーム画面に追加」で全画面アプリとして起動できます。

## 起動方法

### 方法1: 付属の起動スクリプトを使う（PC単体）
```bash
cd /home/eiichi/src/yurukawa_bgm_composer
./run_server.sh
```

### 方法2: スマホで接続する場合（Wi-Fi共有・QRコード読み取り）
スマホとPCを同じWi-Fiに接続した状態で、以下のコマンドを実行します。
```bash
cd /home/eiichi/src/yurukawa_bgm_composer
./run_mobile.sh
```
ターミナルに表示されるQRコードをスマホのカメラで読み取るだけで開けます。

### 方法3: ブラウザで直接開く場合
ビルド不要な構成のため、`index.html` をブラウザにドラッグ＆ドロップして開くことも可能です。

## ファイル構成

```
yurukawa_bgm_composer/
├── index.html              # メイン画面HTML（マシュマロパステル仕様）
├── manifest.json           # PWA用マニフェストファイル
├── run_server.sh           # ローカルサーバー起動スクリプト
├── run_mobile.sh           # スマホ接続用スクリプト（QRコード表示付き）
├── README.md               # 説明書（本ファイル）
├── css/
│   └── style.css           # ゆるかわ・パステルスタイルシート
├── js/
│   ├── app.js              # メインコントローラー（UI・イベント管理）
│   ├── data.js             # シチュエーション、音色、効果音、調性などの定義
│   ├── prompt_generator.js # プロンプト・タイムライン生成エンジン
│   ├── audio_preview.js    # オルゴール・木琴・水滴音の癒やし合成エンジン
│   └── storage.js          # ストレージ管理・JSON入出力・共有URL
└── assets/                 # アイコン画像等の配置場所
```
